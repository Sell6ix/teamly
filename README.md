# Teamly

Веб-приложение, которое помогает быстро собрать пати для кооператива: выбираете игру, стиль и формат — сервис подбирает игроков и открытые сборы с похожим уровнем и часами онлайна.

Это демо без аккаунтов и базы: каталог игроков и матчинг живут в памяти процесса.

## Как подбор работает

Запрос уходит в `POST /api/match`. В выдачу попадают только те, у кого:

- та же игра;
- совместимый стиль (точное совпадение сильнее «близкого»);
- пересекаются окна онлайна;
- уровень не дальше чем на 2 ступени.

Открытый сбор должен ещё совпасть по формату пати и иметь свободные слоты. На карточках виден процент совпадения и короткие причины.

Дальше можно пригласить людей в свою пати или вступить в готовый сбор. Когда слоты заполнены — состав подтверждается.

## Локальный запуск

Нужны Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Приложение слушает [http://127.0.0.1:4317](http://127.0.0.1:4317).

```bash
npm run lint
npm run build
```

## Состояния интерфейса

- Загрузка: скелетоны, пока идёт поиск.
- Пусто: например **It Takes Two** + спидран + утро — в каталоге нет таких игроков.
- Ошибка: на форме критериев включите «Показать состояние ошибки поиска».
