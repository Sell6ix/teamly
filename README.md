# Teamly

Browse-first веб-приложение для сбора пати: каталог игр с обложками, фильтр по типу (Пати / Шутеры / Кооп…), лобби с фильтрами-чипами и шарящаяся ссылка на пати. UI на русском.

В каталоге есть пати-игры вроде **Бункера**, Мафии, Among Us, Gartic Phone, Jackbox и Codenames — с размерами стола 6–12 и своими ролями.

Это демо без аккаунтов и базы: каталог игроков и матчинг живут в памяти процесса.

## Экраны

- `/` — каталог игр (сетка обложек, счётчики «ищут / сборы»)
- `/g/{game}/{style}` — короткий алиас стиля (например `/g/valorant/ranked`)
- Query на лобби: `?size=5&skill=4&hours=evening` (стиль — в path)
- `/party/{id}` — глубокая ссылка на открытый сбор
- `/join/{code}` — приглашение в пати (общий in-memory store на сервере)

В трее пати: **«Открыть сбор»** публикует вашу пати во вкладку «Сборы».

У каждой игры свои поля в лобби: роли/линии/классы (чипы + `?role=`), подписи уровней (ранги/MMR/Hazard) и набор стилей (например, спидран только у DRG).

В карточках игроков и в трее пати — опциональные ссылки Steam / Discord / Riot ID.
В шапке — **Мой профиль** (localStorage): имя, ссылки, регион и голос.

В трее: **«Я ищу»** публикует вас в ленту игроков; **«Открыть сбор»** — во вкладку сборов.
Подтверждение состава копирует бриф (имена, /join, Discord/Steam).

Сборы матчятся мягко: размер ±2 и близкий стиль (Бункер 8 видно при фильтре на 10).

## Как подбор работает

Запрос уходит в `POST /api/match`. В выдачу попадают только те, у кого:

- та же игра;
- совместимый стиль (точное совпадение сильнее «близкого»);
- пересекаются окна онлайна;
- уровень не дальше чем на 2 ступени.

Открытый сбор должен ещё совпасть по формату пати и иметь свободные слоты.

В трее пати всегда есть **«Скопировать ссылку на пати»** → `/join/{code}`.

## Локальный запуск

Нужны Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Приложение слушает [http://127.0.0.1:4317](http://127.0.0.1:4317).

```bash
npm run lint
npm run test
npm run build
```

В карточках — Steam / Discord / Faceit / Riot. «Недавно играли» живёт в браузере и поднимает тех же людей в другой игре (например CS2 ↔ L4D2).

## Состояния интерфейса

- Загрузка: скелетоны, пока обновляется лента лобби.
- Пусто: узкая связка чипов без совпадений — «Сейчас тихо» + ослабить фильтры.
- Ошибка: API матчинга недоступен — сообщение в ленте.
