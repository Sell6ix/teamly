# Teamly

Browse-first веб-приложение для сбора пати: каталог игр с обложками, лобби с фильтрами-чипами и шарящаяся ссылка на пати. UI на русском.

Это демо без аккаунтов и базы: каталог игроков и матчинг живут в памяти процесса.

## Экраны

- `/` — каталог игр (сетка обложек, счётчики «ищут / сборы»)
- `/g/{game}` — лобби игры с чипами и лентой сборов/игроков
- `/party/{id}` — глубокая ссылка на открытый сбор
- `/join/{code}` — приглашение в собирающуюся пати

## Как подбор работает

Запрос уходит в `POST /api/match`. В выдачу попадают только те, у кого:

- та же игра;
- совместимый стиль (точное совпадение сильнее «близкого»);
- пересекаются окна онлайна;
- уровень не дальше чем на 2 ступени.

Открытый сбор должен ещё совпасть по формату пати и иметь свободные слоты.

В трее пати всегда есть **«Скопировать ссылку на пати»** → `/join/{code}`.

## Локальный запуск

Нужны Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Приложение слушает [http://127.0.0.1:4317](http://127.0.0.1:4317).

```bash
npm run lint
npm run build
```

## Состояния интерфейса

- Загрузка: скелетоны, пока обновляется лента лобби.
- Пусто: узкая связка чипов без совпадений — «Сейчас тихо» + ослабить фильтры.
- Ошибка: API матчинга недоступен — сообщение в ленте.
